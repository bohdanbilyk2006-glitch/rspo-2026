## Практична 07. GPU

### Умови

Середовище: Google Colab. CPU: Intel(R) Xeon(R) CPU @ 2.00GHz.  
Видимих віртуальній машині фізичних ядер: 1; логічних процесорів: 2; потоків Numba CPU: 2.  
GPU: Tesla T4, 15360 MiB, драйвер 580.82.07.  
Python: 3.13.15; NumPy: 2.1.3; Numba: 0.61.2.  
ОС: Linux-6.6.122+-x86_64-with-glibc2.39.  
Основний розмір: 1500 × 1000; MAX_ITER = 300.  
X: -2,0…0,6; Y: -1,2…1,2; обчислення float64, результат int32.  
Блок: 16 × 16 потоків; для основного розміру: 94 × 63 блоки.  
Для кожного розміру виконано 3 прогони CPU та GPU після прогріву.

CPU: `njit(parallel=True)` у тому самому Colab, не домашній ПК. Час виміряно через `perf_counter()`; завершення роботи GPU очікується через `cuda.synchronize()`. Компіляція, перевірка та зображення не входять у заміри.

Для CPU взято мінімум. Для GPU всі три складові взято з одного прогону з найменшим сумарним часом. У кожній серії це прогін 3. Разом = туди + ядро + назад. Прискорення = час CPU / час GPU.

### Підсумок для 1500 × 1000

| Реалізація | Час, с | Прискорення від CPU Colab | Збіг |
|---|---:|---:|---|
| CPU Colab, njit parallel | 0,296797383 | ×1,000 | Еталон |
| GPU, лише ядро (07) | 0,026178254 | ×11,338 | 4 розбіжні точки |

Копіювання: (1,714248 + 1,428795) / 29,321297 × 100% = 10,72%.

У кожному прогоні CPU та GPU отримали різну кількість ітерацій для 4 із 1 500 000 пікселів. Результати для решти пікселів збіглися.

### Синхронізація

Без очікування завершення GPU: 0,616792 мс. Із `cuda.synchronize()`: 26,622396 мс. Це два показання одного запуску: перше зняте до очікування, друге зняте після нього. В основну таблицю неправильний замір без очікування не включено.
